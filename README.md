# MathQuest Jr. — 중등연산 교육 게임 🗺️

PRD(중등연산 교육게임)를 **가정용**에 맞게 단순화한 구현입니다.
복잡한 소셜 로그인 대신 **아이디 + 비밀번호 등록만으로** 로그인합니다.

서버가 필요 없는 **정적 웹 게임**이라 GitHub Pages에서 무료로 돌아갑니다.
학습 기록(XP·진도·별·지갑)은 **그 기기의 브라우저(localStorage)** 에 저장됩니다.

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 [.github/workflows/pages.yml](.github/workflows/pages.yml)이
`static/` 폴더를 자동으로 배포합니다.

처음 한 번만 설정이 필요합니다:

1. GitHub 저장소 → **Settings → Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 변경
3. `main`에 push (또는 Actions 탭에서 `Deploy to GitHub Pages` → `Run workflow`)
4. 배포 주소: `https://<사용자명>.github.io/<저장소명>/`
   (이 저장소 기준 → https://mjd2130gt.github.io/mathquest/)

아이 휴대폰에서는 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 집에서 실행 (테스트용)

```
python app.py
```

- pip 설치 불필요 (파이썬 표준 라이브러리만 사용)
- PC에서: http://localhost:5000
- 자녀 휴대폰에서: 콘솔에 표시되는 `http://<PC IP>:5000` (같은 와이파이 필요)

## 구성

| 파일 | 역할 |
|------|------|
| `static/index.html` | 진입 페이지 (모바일 웹 SPA) |
| `static/local-api.js` | 로그인·진도·상점·리포트 저장 (localStorage) |
| `static/questions.js` | 10개 월드 문제 생성기 + 개념 탐구 카드 + 개념 퀴즈 |
| `static/app.js` | 게임 엔진 (월드맵, 배틀, HP/콤보, 적응형 난이도, 대시보드, 리포트) |
| `static/battle.js` · `static/sound.js` | 배틀 연출 · 사운드 |
| `static/style.css` | 모바일 우선 UI |
| `app.py` | 집에서 테스트할 때 `static/`을 띄우는 정적 서버 |
| `migrate_db_to_json.py` | 예전 `mathquest.db` 기록 → 백업 JSON 변환 (1회용) |

## 게임 내용 (PRD 반영)

- **10개 월드 × 5스테이지**: 개념 탐구 → 기초 배틀 → 응용 배틀 → 개념 퀴즈 → 보스 배틀(제한시간)
- **오답 = 힌트 + 재도전** (재도전 성공 시 70% 보상), HP·콤보·별점(정답률 기준 1~3★)
- **적응형 난이도**: 2연속 오답 → 쉬워짐, 5연속 정답 → 어려워짐
- **XP/레벨(1~50)·배지**, 단원별 진도 대시보드
- **학부모 리포트**: 주간 학습 시간, 단원별 정답률, 취약 단원 안내
- 형제·자매는 **각자 아이디**를 만들면 기록이 따로 저장됩니다.

## 기록 저장과 백업 ⚠️

기록은 **게임을 연 그 브라우저에만** 저장됩니다.

- 아이 폰에서 쌓은 기록은 부모 PC에서 보이지 않습니다 (기기마다 별도).
- **랭킹은 같은 기기에 만든 프로필끼리** 겨룹니다.
- 브라우저 데이터·사이트 기록을 지우거나 시크릿 모드로 열면 기록이 사라집니다.

그래서 게임 안에 백업 기능을 넣어 두었습니다:

**📊 나의 모험 기록 → 백업 파일 내려받기 / 백업 파일 불러오기**

가끔 백업 파일을 내려받아 클라우드나 메일에 보관해 두세요.
기기를 바꿀 때도 새 기기에서 "불러오기"로 그대로 옮길 수 있습니다.

### 예전 Flask 서버 기록 옮기기

Railway/로컬 Flask 서버 시절 `mathquest.db`에 쌓인 기록은 이렇게 옮깁니다:

```
python migrate_db_to_json.py
```

사용자마다 **새 비밀번호**를 물어봅니다. (기존 해시는 werkzeug pbkdf2 방식이라
브라우저에서 검증할 수 없어 이 부분만 새로 정합니다. XP·진도·별·지갑은 그대로 옮겨집니다.)
만들어진 `mathquest-backup-*.json`을 게임에서 **백업 파일 불러오기**로 선택하면 끝입니다.

## 가정용으로 단순화한 부분

- Supabase/카카오 로그인 → 브라우저 로컬 저장 + 아이디·비밀번호 (비밀번호는 SHA-256 해시로 저장)
- 친구 랭킹, PWA 오프라인, AI 챗봇 등은 제외 (가정 내 사용 목적)
- 비밀번호는 어디까지나 형제·자매끼리 기록을 섞지 않기 위한 장치입니다.
  기기에 접근할 수 있으면 저장된 값을 볼 수 있으니, **다른 곳에서 쓰는 비밀번호는 쓰지 마세요.**
