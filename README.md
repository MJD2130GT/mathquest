# MathQuest Jr. — 가정용 중등연산 교육 게임 🗺️

PRD(중등연산 교육게임)를 **가정용**에 맞게 단순화한 구현입니다.
복잡한 소셜 로그인 대신 **아이디 + 비밀번호 등록만으로** 로그인합니다.

## 실행 방법

```
pip install flask
python app.py
```

또는 `start.bat` 더블클릭.

- PC에서: http://localhost:5000
- 자녀 휴대폰에서: 서버 실행 시 콘솔에 표시되는 `http://<PC IP>:5000` 접속 (같은 와이파이 필요)
  - 접속이 안 되면 Windows 방화벽에서 Python(포트 5000) 허용을 확인하세요.

## 구성

| 파일 | 역할 |
|------|------|
| `app.py` | Flask 서버 — 간단 로그인(세션), 진도/통계 저장(SQLite), 학부모 리포트 API |
| `static/index.html` | 진입 페이지 (모바일 웹 SPA) |
| `static/questions.js` | 10개 월드 문제 생성기 + 개념 탐구 카드 + 개념 퀴즈 |
| `static/app.js` | 게임 엔진 (월드맵, 배틀, HP/콤보, 적응형 난이도, 대시보드, 리포트) |
| `static/style.css` | 모바일 우선 UI |
| `mathquest.db` | 첫 실행 시 자동 생성되는 데이터 파일 |

## 게임 내용 (PRD 반영)

- **10개 월드 × 5스테이지**: 개념 탐구 → 기초 배틀 → 응용 배틀 → 개념 퀴즈 → 보스 배틀(제한시간)
- **오답 = 힌트 + 재도전** (재도전 성공 시 70% 보상), HP·콤보·별점(정답률 기준 1~3★)
- **적응형 난이도**: 2연속 오답 → 쉬워짐, 5연속 정답 → 어려워짐
- **XP/레벨(1~50)·배지**, 단원별 진도 대시보드
- **학부모 리포트**: 주간 학습 시간, 단원별 정답률, 취약 단원 안내
- 형제·자매는 **각자 아이디**를 만들면 기록이 따로 저장됩니다.

## 가정용으로 단순화한 부분

- Supabase/카카오 로그인 → 로컬 SQLite + 아이디·비밀번호 (비밀번호는 해시 저장)
- 친구 랭킹, PWA 오프라인, AI 챗봇 등은 제외 (가정 내 사용 목적)
